# Limitations

- This is a portfolio prototype, not an affiliated Hugging Face product.
- Private customer data must not be used.
- Synthetic fixtures must be clearly labeled.
- The model must not invent logs, versions, incidents, account states, or permissions.
- High-risk workflows require human approval or are not autonomous.
- Browser code must never receive server-only secrets such as `OLLAMA_API_KEY` or `SUPABASE_SERVICE_ROLE_KEY`.
