# Demo Script

1. A difficult technical ticket arrives with incomplete symptoms.
2. The agent searches docs/issues and checks synthetic telemetry.
3. It compares multiple hypotheses with evidence for and against each.
4. It proposes a safe remediation and updates the synthetic case.
5. The dashboard detects similar failures across accounts and raises an incident candidate.
6. A malicious ticket attempts cross-tenant data access and policy blocks it.
7. A case with missing diagnostics causes the agent to ask for the smallest useful extra evidence.
8. Evaluation metrics show diagnosis, retrieval, security, latency, and regression results.
